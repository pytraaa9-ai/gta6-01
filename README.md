**Solmar Nights** — an original open-world crime game in the sun-soaked fictional city of Solmar City: steal and drive cars, outrun the SPD wanted system, fight with fists and pistol, and run five story missions for Rosa's crew, with a live minimap, day/night cycle, and save progress.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080 — WASD to move/drive, E to steal a car, mouse to aim, click to shoot, Space to punch, M for the next mission, P to pause.
